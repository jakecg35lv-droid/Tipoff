# MM Fantasy App

March Madness Fantasy — snake draft, live scoring, bracket tracking.

## Quick Start

1. Open `index.html` in any modern browser
2. Create an account (any email + 6+ char password)
3. Click **Create League** and follow the setup tutorial
4. Share your 6-character league code with managers
5. Start the draft!

## How It Works

- **Draft**: Snake draft — rounds alternate direction. Commissioner controls the timer.
- **Scoring**: Fantasy points from PTS/REB/AST/STL/BLK (customizable weights in Settings).
- **Second Chance**: Enable in Settings → auto-opens after Round of 64 completes. Managers can claim undrafted players.
- **Bracket**: Commissioner clicks teams to advance winners. Owned players get initials badges.
- **Standings**: Simulate Stats button randomly increments scores so you can preview standings.

## Features

- Snake draft with pick timer and animations
- Commissioner tutorial on first launch
- Player pool with seed/stat filtering
- School logos from ESPN CDN
- Pick announcement animations
- Team rosters with fantasy points
- Live standings with rank change indicators
- Tournament bracket with click-to-advance
- Second Chance pickup window
- Activity feed
- League code join flow
- Export / share league code

## Reset

To clear all data, open browser DevTools → Application → Local Storage → clear all `mmfantasy-*` keys.

## No Install Needed

Pure HTML/CSS/JS. No server, no npm, no build step.
